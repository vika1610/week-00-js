## Главная задача (из плана): список пользователей

Загрузи пользователей с `https://jsonplaceholder.typicode.com/users` и выведи список имён на страницу. Пока данные грузятся — показывай «Загрузка…», а при ошибке — сообщение об ошибке.

Разбей на функции в `solution.js`:

1. `loadUsers(url)` — `async`-функция: делает `fetch`, проверяет `response.ok`, возвращает массив пользователей. Если ответ не ok — **выбрасывает ошибку** (`throw new Error(...)`).
2. `getNames(users)` — возвращает массив имён (`name`).
3. `renderUsers(container, url)` — `async`-функция, которая работает со страницей:
   - сразу пишет в `container` текст `Загрузка…`;
   - при успехе заменяет содержимое на список `<ul>` с `<li>` для каждого имени;
   - при ошибке пишет текст, начинающийся с `Ошибка` (например `Ошибка: не удалось загрузить`).

Затем в `main.js` вызови `renderUsers` для контейнера на странице и проверь в браузере.

> Проверь ошибку вручную: испорть адрес (например `/userss`) — что покажет страница?

## Мини-задача 1: `delay(ms)`

Верни промис, который выполнится через `ms` миллисекунд. Пригодится, чтобы увидеть «Загрузка…» подольше:

```js
await delay(1000) // подождать секунду
```

## Мини-задача 2: `parseJSONSafe(text, fallback)`

Разбери JSON-строку. Если строка некорректная — не падай, а верни `fallback`:

```js
parseJSONSafe('{"a":1}', null) // { a: 1 }
parseJSONSafe('не json', [])   // []
```

## Мини-задача 3: `toJSON(users)`

Преврати массив пользователей в строку JSON, оставив только `id` и `name`:

```js
toJSON([{ id: 1, name: 'Leanne', email: '...' }]) // '[{"id":1,"name":"Leanne"}]'
```
