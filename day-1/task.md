## Главная задача (из плана): `formatPrice(price)`

Напиши функцию, которая превращает число в цену в рублях:

```js
formatPrice(1234.5)   // «1 234,50 ₽»
formatPrice(0)        // «0,00 ₽»
formatPrice(1000000)  // «1 000 000,00 ₽»
```

- Всегда ровно 2 знака после запятой.
- Разряды разделены пробелом, дробная часть — через запятую.
- В конце — пробел и знак `₽`.

> Подсказка из плана: посмотри на метод `toLocaleString`.

## Мини-задача 1: `greet(name, greeting)`

Функция-приветствие с **параметрами по умолчанию** и **шаблонной строкой**:

```js
greet('Вика')           // «Привет, Вика!»
greet('Вика', 'Добрый день') // «Добрый день, Вика!»
greet()                 // «Привет, гость!»
```

## Мини-задача 2: `describeType(value)`

Верни название типа значения по-русски:

| Значение | Результат |
|---|---|
| `'текст'` | `'строка'` |
| `42`, `NaN` | `'число'` |
| `true` | `'булево'` |
| `undefined` | `'undefined'` |
| `null` | `'null'` |
| `[1, 2]` | `'массив'` |
| `{ a: 1 }` | `'объект'` |
| `() => {}` | `'функция'` |

Осторожно: `typeof null` и `typeof []` ведут себя неожиданно — проверь в консоли браузера!

## Мини-задача 3: `isAdult(age, minAge)`

Напиши как **стрелочную функцию**. Возвращает `true`, если `age >= minAge`. По умолчанию `minAge = 18`.

```js
isAdult(20)     // true
isAdult(16)     // false
isAdult(16, 16) // true
```
