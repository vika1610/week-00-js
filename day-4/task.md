**Теория (20 мин):** модули `import` / `export`, `this`, классы (обзор), обработка событий DOM.
Читать: learn.javascript.ru → «Модули, введение», «Экспорт и импорт», «Методы объекта, this», «Классы: базовый синтаксис», «Введение в браузерные события».

**Практика (35 мин).** Сегодня два способа проверки:

```bash
npm run test:day4     # тесты функций
npm run serve:day4    # открыть страницу index.html в браузере (адрес появится в терминале)
```

> Почему нельзя просто дважды кликнуть по `index.html`? Браузер не загружает модули (`type="module"`) с адреса `file://` — нужен локальный сервер. Команда `serve:day4` его запускает. Остановить — `Ctrl + C`.

## Главная задача (из плана): страница с модулями

Файлы этого дня:

- `solution.js` — **модуль с утилитами** (функции с `export`);
- `main.js` — **главный скрипт** страницы, импортирует утилиты из `solution.js`;
- `index.html` — страница, подключает `main.js` через `<script type="module">` (уже готова).

Что сделать:

1. В `solution.js` напиши `setupToggleButton(button, firstText, secondText)`: при **клике** по кнопке её текст переключается между `firstText` и `secondText`. Сначала на кнопке `firstText`.
2. В `main.js` импортируй `setupToggleButton`, найди кнопку на странице и вызови функцию.
3. Открой страницу через `npm run serve:day4` и проверь кликами.

## Мини-задача 1: `toggleText(current, a, b)`

Чистая функция-помощник: если `current === a` — вернуть `b`, иначе вернуть `a`.
Попробуй использовать её внутри `setupToggleButton`.

## Мини-задача 2: `capitalize(str)`

`capitalize('привет')` → `'Привет'`, `capitalize('')` → `''`.
Используй её в `main.js`, например чтобы вывести заголовок с большой буквы.

## Мини-задача 3: класс `Product` и `this`

```js
const mug = new Product('Кружка', 450)
mug.title           // 'Кружка'
mug.price           // 450
mug.getLabel()      // 'Кружка — 450 ₽'
mug.applyDiscount(10) // уменьшает цену на 10 %
mug.price           // 405
```

Внутри методов обращайся к полям через `this`.
