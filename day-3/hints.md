# Подсказки · Неделя 0 · День 3

<details>
<summary>Подсказка 1 — намёк</summary>

- `mergeSettings`: оператор `...` умеет «раскладывать» объект внутрь нового объекта. Что будет, если разложить два объекта подряд?
- Для каждой задачи с массивом сначала спроси себя: «Мне нужен новый массив той же длины? Меньшей длины? Одно значение? Один элемент? Да/нет?» Это и подскажет метод.
- `sum`: rest-параметр собирает все аргументы в массив.
- `getLabel`: в скобках функции можно сразу написать `{ title, price }` вместо `product`.

</details>

<details>
<summary>Подсказка 2 — конкретнее</summary>

| Что нужно | Метод |
|---|---|
| новый массив той же длины (названия) | `map` |
| часть элементов (дешёвые) | `filter` |
| одно значение из всех (сумма) | `reduce` |
| один элемент (по id) | `find` |
| да/нет «есть ли хотя бы один» | `some` |

- `sortByPrice`: `sort` **меняет исходный массив**! Сначала сделай копию массива, а потом сортируй её.
- `sort` без функции сравнивает элементы как строки. Ему нужна функция сравнения `(a, b) => ...`.

</details>

<details>
<summary>Подсказка 3 — почти решение</summary>

- `mergeSettings`: `{ ...первый, ...второй }` — кто записан позже, тот и «побеждает».
- `getTotal`: `products.reduce((acc, product) => /* ... */, 0)` — не забудь начальное значение `0`.
- `sortByPrice`: `[...products].sort((a, b) => /* число: отрицательное — a раньше b */)`.
- `sum(...numbers)` — внутри `numbers` обычный массив, а сложить массив ты уже умеешь через `reduce`.

</details>
