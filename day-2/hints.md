# Подсказки · Неделя 0 · День 2

<details>
<summary>Подсказка 1 — намёк</summary>

- `makeCounter`: замыкание — это когда внутренняя функция «помнит» переменные внешней функции, даже после того как внешняя закончила работу. Где должна жить переменная со счётом, чтобы методы её видели, а снаружи её не было?
- `makeIdGenerator`: очень похоже на счётчик, только возвращаешь не объект, а одну функцию.
- `copyObject`: вспомни spread-оператор `...` или `Object.assign`.
- `deepCopy`: в современных браузерах и Node есть встроенная функция для глубокого копирования. Поищи на MDN «structured clone».

</details>

<details>
<summary>Подсказка 2 — конкретнее</summary>

- `makeCounter`:
  ```js
  let count = /* старт или 0 */
  return {
    inc() { /* ... */ },
    // ...
  }
  ```
  В объекте должны быть только функции — самого `count` там быть не должно.
- `makeIdGenerator`: внутри — `let n = 0`, а возвращаемая функция увеличивает `n` и собирает строку шаблоном.
- `copyObject`: `{ ...obj }` создаёт новый объект. Но копируется только «первый уровень» — вложенные объекты остаются общими по ссылке.

</details>

<details>
<summary>Подсказка 3 — почти решение</summary>

- `makeCounter(start = 0)` — параметр по умолчанию из прошлого дня.
- `deepCopy`: `structuredClone(obj)`. Для интереса попробуй ещё старый способ через `JSON.parse(JSON.stringify(obj))` и подумай, что он не умеет копировать (даты, функции, `undefined`).

</details>
