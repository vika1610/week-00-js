## Главная задача (из плана): `makeCounter()`

Функция возвращает объект-счётчик с методами `inc()`, `dec()`, `value()`.
Само число должно храниться **в замыкании**, а не в свойстве объекта — снаружи его нельзя поменять напрямую.

```js
const counter = makeCounter()
counter.inc()
counter.inc()
counter.dec()
counter.value() // 1

const other = makeCounter(10) // необязательный стартовый параметр
other.value() // 10 — и он не зависит от первого счётчика
```

## Мини-задача 1: `makeIdGenerator(prefix)`

Ещё одно замыкание. Возвращает **функцию**, которая при каждом вызове выдаёт новый id:

```js
const nextTaskId = makeIdGenerator('task')
nextTaskId() // 'task-1'
nextTaskId() // 'task-2'
```

## Мини-задача 2: `copyObject(obj)`

Верни **поверхностную копию** объекта: новый объект с теми же свойствами.
Изменение копии не должно менять оригинал.

```js
const user = { name: 'Аня', age: 25 }
const copy = copyObject(user)
copy.name = 'Оля'
user.name // всё ещё 'Аня'
```

## Мини-задача 3: `deepCopy(obj)`

То же, но для **вложенных** объектов: копия вложенного объекта тоже должна быть независимой.

```js
const user = { name: 'Аня', address: { city: 'Москва' } }
const copy = deepCopy(user)
copy.address.city = 'Казань'
user.address.city // всё ещё 'Москва'
```
